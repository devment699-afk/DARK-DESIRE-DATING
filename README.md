# DARK DESIRE DATING 🖤🔥

> **Ignite Secret Anonymous Desires** — A high-octane real-time stranger dating and anonymous chat Android application powered by modern Android architecture and WebSocket instant matchmaking.

---

## 🌟 Key Features

- 🕵️ **100% Anonymous & Secret**: No phone numbers, no social logins. Pick an alias, select your desire mood, and step into the shadows.
- 📡 **Stranger Roulette & Radar**: Real-time pulsing radar scanner matching you instantly with strangers based on preferences.
- 💬 **Live 1-on-1 Chat**: Instant encrypted messaging, typing indicators, and real-time status.
- ⚡ **Instant Skip & Next Stranger**: Didn't vibe? Tap **NEXT** to skip instantly to a new soul.
- 🌐 **Discover Online Users**: Browse online secret profiles in real-time.
- 🖤 **Dark Desire Aesthetic**: Jet-black background with neon crimson & magenta accents.
- ☁️ **Full GitHub Actions CI/CD**: Cloud-compiled APK builds with zero device clutter.

---

## 🏗️ Architecture

- **Android App**: Java / AndroidX / Material Design 3 / OkHttp WebSockets / ViewBinding
- **Server**: Node.js WebSocket Matchmaking & Queue Server (`/server`)
- **CI/CD**: GitHub Actions (`.github/workflows/build-apk.yml`)

---

## 🚀 Building & Downloading APK
