# Dark Desire Dating - Matchmaking WebSocket Server

Lightweight real-time WebSocket matchmaking server for DARK DESIRE DATING.

### Instant 1-Click Cloud Deployment
You can deploy this server for free on:
- **Render.com**: Create a New Web Service -> Connect this repo -> Set Root Directory to `server` -> Build Command `npm install` -> Start Command `node server.js`
- **Railway.app / Glitch / Fly.io / Heroku**

Once deployed, copy your WebSocket URL (e.g. `wss://your-app.onrender.com`) and paste it inside the **Profile -> Settings -> Realtime Server URL** in the Android App!
